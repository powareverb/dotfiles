# Notes

Mise is the thing that has all the tools!

To get started running things on one liners:

```sh
mise exec -- dotnet --version

```

Or instead, kick up a shell:

```sh
# Activate mise
eval "$(mise activate)"
```

Update all your trash tools

```sh
mise up --bump
```

Use a new tool you didn't have before

```sh
mise use just

```
